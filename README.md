# 두툼버거 주방

비유나 첫 글자로 적힌 주문표를 읽고 버거를 쌓아 손님에게 내는 브라우저 요리 게임이에요.

- 장사는 하루 150초, 낸 버거 개수가 점수예요.
- 그릴에서 패티를 굽고, 재료 15가지를 주문표 순서대로 아래에서부터 쌓아요.
- 덜 익은 패티가 들어간 버거는 0.5개로 쳐요.
- 어려운 손님은 "다음 손님"으로 넘길 수 있어요 (-5초, 정답을 2초 보여 줘요).

## 실행

`index.html`을 브라우저로 열면 바로 할 수 있어요. 따로 설치할 것은 없어요.

GitHub Pages나 파일로 열면 랭킹은 그 기기에만 저장돼요.
